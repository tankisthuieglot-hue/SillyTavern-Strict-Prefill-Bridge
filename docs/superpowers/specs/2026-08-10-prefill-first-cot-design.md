# Эмуляция префилла в стиле Kiro Gateway

## Цель

Дать моделям без нативного assistant-prefill заданное начало ответа через историю диалога: префилл выглядит как незаконченный ответ ассистента, после которого модель получает строгую скрытую команду продолжить его с последнего символа.

Это не нативный API-prefill и не способ отключить внутреннее мышление модели. Режим повторяет наблюдаемую механику Kiro Gateway: последний assistant-фрагмент переносится в историю, а текущим пользовательским сообщением становится `Continue`.

## Интерфейс

Отдельная галочка `Эмуляция как Kiro Gateway (экспериментально)` выключена по умолчанию и сохраняется вместе с настройками расширения. Для работы должны быть включены основная галочка строгого префилла и галочка эмуляции.

## Поведение

Когда режим включён:

- `json_schema` не добавляется;
- после обычного пользовательского сообщения добавляется `{ role: 'assistant', content: prefix }`;
- следом добавляется скрытая user-команда продолжить предыдущее сообщение ровно с последнего символа, не перезапуская и не повторяя его;
- если префилл заканчивается открытым тегом или незавершённой структурой, команда требует заполнить её содержимым перед закрытием;
- если запрос Continue уже заканчивается сообщением ассистента, префилл дописывается в это сообщение, чтобы не создавать две роли assistant подряд;
- скрытая команда существует только в исходящем запросе и не сохраняется в чате;
- видимый ответ начинается с того же префилла без дублирования, если провайдер его повторил;
- минимум символов и JSON-защита кавычек `<info>...</info>` не применяются, потому что JSON-обёртки нет.

Режим не ограничен Gemini и проходит через выбранное подключение SillyTavern. Расширение не меняет `reasoning_effort`, `include_reasoning`, `thinkingLevel`, лимиты токенов, семплинг или модель.

## Поток данных

1. SillyTavern формирует запрос текущего провайдера.
2. Расширение добавляет в историю assistant-префилл.
3. Расширение добавляет строгую скрытую user-команду продолжения.
4. Провайдер возвращает обычный текст без Schema-обёртки.
5. Расширение добавляет префилл к видимому сообщению, если провайдер не повторил его сам.

Обычный Structured Outputs / JSON Schema режим остаётся без изменений, когда экспериментальная галочка выключена.
