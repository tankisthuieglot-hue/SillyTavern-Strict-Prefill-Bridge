# Strict Prefill Bridge для SillyTavern

Расширение заставляет структурированный ответ начинаться с заданного текста. По умолчанию это `<think>`, но можно указать `<thinking>` или произвольный многострочный префилл.

## Как это работает

- Для Google AI Studio и Vertex AI расширение задаёт JSON Schema с двумя полями: `prefix` и `content`. Поле `prefix` имеет единственное допустимое значение через `enum`, а `propertyOrdering` ставит его перед продолжением.
- При включённом **Двухшаговом CoT** SillyTavern сначала делает отдельную скрытую генерацию до 512 токенов через текущее подключение. Расширение читает сырой ответ, включая нативный thinking, и для `<think>` собирает полноценный блок `<think>…</think>`.
- Полученный блок целиком становится обязательным началом основного ответа через ту же JSON Schema. Поэтому основная модель должна воспроизвести не пустой тег, а уже заполненный CoT и затем продолжить ответ.
- Для OpenAI-совместимых источников используется строковое поле с regex `pattern`, требующим точного префикса в начале.
- Модель генерирует структурированный объект. Расширение распаковывает его в обычный текст во время стрима и перед сохранением сообщения.
- Предварительная генерация не сохраняется отдельным сообщением в чате. Видимый ответ распаковывается из основного структурированного ответа как обычно.

## Поведение

- Normal, Regenerate, Swipe и Continue получают новый префилл.
- При Continue новый префилл добавляется в продолжение текущего сообщения.
- Для прямых Google AI и Vertex AI можно задать минимальное число символов после обязательного блока. Это не даёт Gemini законно закрыть JSON слишком рано; `0` отключает ограничение, для длинных трекеров попробуйте `16000–24000`.
- Для прямых Google AI и Vertex AI двойные кавычки внутри блоков `<info>...</info>` временно кодируются перед основным запросом и автоматически восстанавливаются в ответе. Это обходит остановку Gemini посреди JSON-строки HTML-атрибута.
- Экспериментальная галочка **Двухшаговый CoT** использует два API-запроса на каждый Normal, Regenerate, Swipe или Continue. Она выключена по умолчанию. Если предварительный запрос завершился ошибкой, расширение показывает предупреждение и выполняет обычный строгий префилл без сгенерированного CoT.
- В основном, втором запросе показ нативной сводки thinking отключается, чтобы перед ответом не появлялись два блока рассуждений. Внутреннее мышление модели и выбранный Thinking Level при этом сохраняются.
- Первый проход использует сырой ответ `generateRawData`, поэтому пользовательские Regex, стоп-строки и очистка обычного AI Output не могут отрезать начало сгенерированного CoT.
- Префилл сохраняется буквально, включая пробелы, Unicode и переносы строк.
- Нативное мышление Gemini, Reasoning Effort / Thinking Level, лимит выходных токенов, модель и семплинг не изменяются.
- Оба запроса идут через выбранный в SillyTavern провайдер и уже сохранённые настройки подключения. Расширение не читает ключи и не обращается к отдельному внешнему серверу.

## Совместимость

- Google AI Studio и Vertex AI: строгий `enum`; в двухшаговом режиме единственным допустимым значением становится весь предварительно сгенерированный блок.
- NanoGPT: отдельные поля `prefix` + `content` с `enum`, без несовместимого regex `pattern`. Если конкретная модель или выбранный маршрут NanoGPT не поддерживает Structured Outputs, провайдер всё равно не сможет гарантировать префилл.
- OpenRouter и другие OpenAI-совместимые источники: `json_schema` с regex, если выбранный маршрут действительно исполняет Structured Outputs.
- Прямой Anthropic в SillyTavern 1.18 не активируется: текущий поток ответа не возвращает forced-tool input как обычный текст. Для Claude используйте OpenRouter или другой OpenAI-совместимый маршрут со Structured Outputs.
- Если провайдер игнорирует ограничения Schema, несовпадающий префилл не распаковывается. Двухшаговый режим не может обойти отсутствие настоящей поддержки Structured Outputs у маршрута.

Structured Outputs не отменяет блокировку запроса системой безопасности провайдера. Если провайдер не вернул ответ вообще, расширению нечего распаковывать.

## Установка

В SillyTavern откройте **Extensions → Install extension** и вставьте адрес:

```text
https://github.com/tankisthuieglot-hue/SillyTavern-Strict-Prefill-Bridge
```

Для ручной установки скопируйте рабочие файлы расширения в:

```text
SillyTavern/data/default-user/extensions/strict-prefill-bridge
```

Перезапустите SillyTavern или обновите страницу. Настройка появится в панели Extensions под названием **Strict Prefill Bridge**.
