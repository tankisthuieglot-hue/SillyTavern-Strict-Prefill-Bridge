# Strict Prefill Bridge для SillyTavern

Расширение заставляет структурированный ответ начинаться с заданного текста. По умолчанию это `<think>`, но можно указать `<thinking>` или произвольный многострочный префилл.

## Как это работает

- Для Google AI Studio и Vertex AI расширение задаёт JSON Schema с двумя полями: `prefix` и `content`. Поле `prefix` имеет единственное допустимое значение через `enum`, а `propertyOrdering` ставит его перед продолжением.
- При включённой **Эмуляции как Kiro Gateway** расширение вместо Schema добавляет префилл в историю как `assistant`-сообщение, а после него — скрытое `user: Continue`. Такой же принцип использует Kiro Gateway: модель получает префилл как уже написанную часть истории и отвечает на просьбу продолжить.
- Для OpenAI-совместимых источников используется строковое поле с regex `pattern`, требующим точного префикса в начале.
- Модель генерирует структурированный объект. Расширение распаковывает его в обычный текст во время стрима и перед сохранением сообщения.
- Скрытое `user: Continue` существует только в исходящем запросе и не сохраняется отдельным сообщением в чате. Сам префилл добавляется к видимому ответу расширением.

## Поведение

- Normal, Regenerate, Swipe и Continue получают новый префилл.
- При Continue новый префилл добавляется в продолжение текущего сообщения.
- Для прямых Google AI и Vertex AI можно задать минимальное число символов после префилла. Это не даёт Gemini законно закрыть JSON слишком рано; `0` отключает ограничение, для длинных трекеров попробуйте `16000–24000`. В режиме **Эмуляции как Kiro Gateway** Schema не используется, поэтому минимум символов не действует.
- В обычном Schema-режиме для прямых Google AI и Vertex AI двойные кавычки внутри блоков `<info>...</info>` временно кодируются перед запросом и автоматически восстанавливаются в ответе. Это обходит остановку Gemini посреди JSON-строки HTML-атрибута. В режиме эмуляции JSON отсутствует, поэтому кодирование не требуется.
- Экспериментальная галочка **Эмуляция как Kiro Gateway** действует для текущего подключения SillyTavern: Google AI, Vertex AI, NanoGPT, OpenRouter, прямого Claude и других chat-completions маршрутов. Она выключена по умолчанию и не меняет Reasoning Effort / Thinking Level, `includeThoughts`, лимит токенов или семплинг. Это история `assistant → user: Continue`, а не нативная функция assistant-prefill API.
- Префилл сохраняется буквально, включая пробелы, Unicode и переносы строк.
- Нативное мышление Gemini, Reasoning Effort / Thinking Level, лимит выходных токенов, модель и семплинг не изменяются.
- Используются выбранный в SillyTavern провайдер и уже сохранённые данные подключения; расширение не читает ключи и не выполняет собственные сетевые запросы.

## Совместимость

- Google AI Studio и Vertex AI: по умолчанию строгий `enum`; с эмуляцией Kiro Gateway — `assistant`-префилл в истории и скрытое `Continue` без JSON Schema.
- NanoGPT: отдельные поля `prefix` + `content` с `enum`, без несовместимого regex `pattern`. Если конкретная модель или выбранный маршрут NanoGPT не поддерживает Structured Outputs, провайдер всё равно не сможет гарантировать префилл.
- OpenRouter и другие OpenAI-совместимые источники: `json_schema` с regex, если выбранный маршрут действительно исполняет Structured Outputs.
- Прямой Anthropic в SillyTavern 1.18 не активируется в обычном Schema-режиме: текущий поток ответа не возвращает forced-tool input как обычный текст. Режим эмуляции Kiro Gateway не использует Schema и поэтому доступен и для этого маршрута.
- Если провайдер игнорирует ограничения Schema в обычном режиме, несовпадающий префилл не распаковывается. В режиме эмуляции расширение показывает перед продолжением тот же префилл, который был добавлен в историю запроса.

Structured Outputs не отменяет блокировку запроса системой безопасности провайдера. Если провайдер не вернул ответ вообще, расширению нечего распаковывать.

## Установка

В SillyTavern откройте **Extensions → Install extension** и вставьте адрес:

```text
https://github.com/tankisthuieglot-hue/SillyTavern-Strict-Prefill-Bridge
```

Для ручной установки скопируйте рабочие файлы расширения в:

```text
SillyTavern/data/default-user/extensions/strict-prefill-bridge
```

Перезапустите SillyTavern или обновите страницу. Настройка появится в панели Extensions под названием **Strict Prefill Bridge**.
