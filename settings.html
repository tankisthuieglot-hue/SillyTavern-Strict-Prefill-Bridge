Strict Prefill Bridge
<think> продолжение модели Включён
Двухпроходный: первый скрытый запрос заполняет ваш CoT-шаблон по шагам, второй пишет ответ, отталкиваясь от готового рассуждения. Блок сохраняется в сообщении как <think>…</think>. Использует два API-запроса. Работает для Normal, Regenerate и Swipe (не Continue).
В двухпроходном режиме — тег, которым начинается блок рассуждения (закрывающий выводится автоматически). В режиме «только префилл» — текст, которым принудительно начинается ответ.
Максимальный размер ответа в первом (скрытом) запросе двухпроходного режима. Для больших шаблонов вроде Emotionalism CoT держите 16384 и выше; если блок обрывается на середине — увеличьте.
Только для двухпроходного режима: заставить финальный ответ начинаться с этого текста через JSON Schema. Пусто — ответ начинается как решит модель. При заполнении кавычки в HTML-трекерах кодируются автоматически.
0 — без ограничения. Анти-лень: применяется и к скрытому CoT-запросу, и к ответу с принудительным началом. Если модель заполняет шаблон одной строкой на шаг — поставьте 8000–16000. Лимит токенов и уровень мышления не меняются.
Настоящий префилл удалён из Gemini API начиная с 3.6 — расширение эмулирует его: двухпроходный режим генерирует заполненный CoT-блок отдельным запросом и обусловливает им основной ответ. Провайдер, ключи и уровень мышления берутся из текущих настроек SillyTavern.
Для Gemini рекомендуется выключить стриминг (как и в самих пресетах). Расширение не читает ключи и не обращается к внешнему серверу.
